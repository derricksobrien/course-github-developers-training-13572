# GitHub for Developers Training

> **Source:** Atmosera | **Duration:** 2 days (6 hours) | **Level:** Intermediate
> 
> **Prerequisites:** - All users need GitHub account
- Git experience helpful

## Course Overview

Give your developers confidence with Git and GitHub with hands-on, practical training from GitHub Professional Services. With GitHub for Developers, your team will spend two days working with a GitHub Expert to gain a solid understanding of Git, how to apply the GitHub Flow in their existing projects, and how to handle common situations that occur when working in Distributed Version Control Systems. Most importantly, your team will learn how to collaborate more effectively to write quality code.

## Learning Outcomes

By completing this course, you will be able to:

- Collaborate effectively
- Maximize Git and GitHub
- Implement the GitHub Flow
- Troubleshoot common issues

## Course Structure

This course is organized into 4 modules spanning 2 days (6 hours).

### Module 1: Lesson 1: GitHub Flow and Git Basics

**Duration:** 3 hours

**Topics:**
- GitHub Flow
- Working locally
- Git configurations
- Git aliases
- Collaborating in pull requests and issues
- Branching with Git
- Editing on GitHub
- Merging pull requests

### Module 2: Lesson 2: Handling Merge Conflicts

**Duration:** 3 hours

**Topics:**
- Understanding how merge conflicts happen
- Resolving merge conflicts on GitHub
- Resolving merge conflicts on the command line

### Module 3: Lesson 3: Advanced Workflows

**Duration:** 3 hours

**Topics:**
- Understanding workflows
- Protected branches
- Git bisect
- Helpful Git commands
- Atomic commits
- Reverting commits
- Viewing local changes
- Tags and release

### Module 4: Lesson 4: Repository Management

**Duration:** 3 hours

**Topics:**
- Creating local repositories
- Fixing commits
- Git reset
- Cherry picking
- Git reflog
- Merge strategies
- Git rebase
- Git squash


## Target Audience

- Developers
